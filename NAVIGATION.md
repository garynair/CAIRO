# How to Navigate CAIRO

Prefer a visual, clickable version? Open the [CAIRO Navigator](https://claude.ai/artifact/F1YyskXBG7pS81ahGjH9Pz) — a one-page register of all twelve modules and five capstones with progress checkboxes. This file is the plain-text equivalent that travels with the repo.

## Repository layout

```
CAIRO/
├── learning/     the course itself — start here
├── solutions/    reference solutions — check your work here, after
├── anki/         a ready-made flashcard deck
└── README.md     project overview
```

## The path through it

1. **Read the map.** [`learning/CURRICULUM.md`](learning/CURRICULUM.md) (module and project plan) and [`learning/PREREQUISITES.md`](learning/PREREQUISITES.md) (assumed entry knowledge).
2. **Work each module in order**, `mod-101-foundations` through `mod-112-cairo-operating-model`:
   - Read the module's `README.md` first — it states what you should be able to do afterward.
   - Read the numbered chapter files in order (`01-*.md`, `02-*.md`, ...) or `lecture-notes.md` where a module uses one file instead of several.
   - Do every file in `exercises/` — write the actual deliverable it asks for. An exercise you only read was not done.
   - Take `quiz.md`.
   - **Only after attempting it yourself**, open the matching file in `solutions/modules/mod-XXX-.../` — either `SOLUTION.md` per exercise or `quiz-key.md`.
3. **Drill with the Anki deck** ([`anki/cairo-deck.txt`](anki/cairo-deck.txt)) alongside your reading — see [`anki/README.md`](anki/README.md) for import steps.
4. **Work the five capstones last**, `project-301` through `project-305`, in [`learning/projects/`](learning/projects/):
   - Read `SCENARIO.md` for the fictional company context.
   - Read the project's `README.md` for the deliverable list and suggested schedule.
   - Produce each deliverable against its spec in `deliverables/` — every spec has a rubric.
   - Compare against [`solutions/projects/`](solutions/projects/) only after finishing.

## What "done" looks like for a module

- You wrote every exercise deliverable yourself before opening its solution.
- You can state the module's "what you will leave with" objectives without rereading the README.
- You took the quiz and understand why you missed anything you missed — not just what the right answer was.
