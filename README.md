# CAIRO — Chief AI Risk Officer Curriculum

A complete, self-paced curriculum for the **Chief AI Risk Officer (CAIRO)** seat: the executive who owns enterprise AI strategy, AI portfolio risk and P&L attribution, board-level AI risk oversight, and CEO/board/regulator-facing positioning on AI.

Twelve modules and five multi-week executive capstones, each with lecture notes, exercises, quizzes, and worked reference solutions.

**New here? Open the [CAIRO Navigator](https://claude.ai/artifact/F1YyskXBG7pS81ahGjH9Pz)** — a one-page register of every module and capstone with progress checkboxes, or read [`NAVIGATION.md`](NAVIGATION.md) for the plain-text version.

## Layout

- **[`learning/`](learning/)** — the course itself: modules, exercises, quizzes, and capstone project specs. Start here.
- **[`solutions/`](solutions/)** — reference solutions and worked capstone deliverables. One defensible approach per exercise, with reasoning notes on where it could plausibly have gone differently — not *the* answer.
- **[`anki/`](anki/)** — a ready-made flashcard deck covering named frameworks, citations, and structural facts across all twelve modules.

## How to use this

1. Read [`learning/CURRICULUM.md`](learning/CURRICULUM.md) for the full module and project map.
2. Work through `learning/lessons/mod-101-foundations/` onward, in order.
3. Attempt each exercise before opening its matching file under `solutions/modules/`.
4. Drill vocabulary with the [Anki deck](anki/) as you go.
5. Work the five capstones in `learning/projects/` — each simulates the first 90 days (and beyond) as the inaugural CAIRO at a fictional company, producing a portfolio of board- and regulator-presentable artifacts.

See [`NAVIGATION.md`](NAVIGATION.md) for the full module list, hours, and what "done" looks like per module.

## Provenance

This curriculum began as the Chief AI Officer track of the open-source [AI Career Curriculum](https://github.com/ai-governance-curriculum) project (MIT License). It has been rebranded, retitled around the risk-officer seat specifically, and is maintained independently here.
